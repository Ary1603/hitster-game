# QR Spotify Game

Web app game based on physical QR cards connected to Spotify playback.

## Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend

- NestJS
- TypeScript
- Prisma
- PostgreSQL
- Swagger

### Infrastructure

- Docker
- Docker Compose
